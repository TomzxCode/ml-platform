# Spec: `mlx completion`

## Overview

The `completion` group emits shell completion scripts for supported shells.
It implements FEAT-p1 FR-15.
Parent feature: FEAT-p1 (Unified ML CLI); requirement IDs stay owned by FEAT-p1.

## Commands and inputs

| Command | Arguments | Purpose |
|---|---|---|
| `completion` | `<shell>` | Emit a completion script for that shell |

No spec file is submitted to this group; the submitted input is the shell name.

## Input contract

| Input | Required | Rules |
|---|---|---|
| shell | Yes | One of `bash`, `zsh`, `fish` |

## Local validation

- An unsupported shell name exits 1 and lists the supported shells.
- Completions are generated by cyclopts from the registered command tree, so they stay in sync automatically (FEAT-p1 Phase 5).

## Output

The completion script goes to stdout as-is, since it is consumed by the shell, not by humans.
Whether `--json` applies here is an open question, because FR-12 says every command when requested, yet this output is a script.

## Open questions

- Whether `--json` must wrap the script (likely exempt, needs a decision recorded against FR-12).
- Whether more shells (for example PowerShell, used on Windows per NFR-5) join the supported set in v1.
