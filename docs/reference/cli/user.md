# mlx user

Users visible to the caller.

## Subcommands

| Subcommand | Arguments | Purpose |
|---|---|---|
| `list` | | Users with team memberships |
| `get` | `<id-or-email>` | One user's identity, teams, and workspaces |

Listing users requires permission; workspace membership is managed with [`mlx workspace member`](workspace.md).
